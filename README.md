# سندك نحو حياة حقيقية | Sanadak

تطبيق إسلامي شامل يهدف إلى تعزيز الجانب الروحي للمسلم من خلال الذكر، السكينة، والتعلم.

## المميزات
- **الأذكار اليومية:** تتبع أذكار الصباح والمساء بانتظام.
- **مواقيت الصلاة:** تنبيهات دقيقة لمواقيت الصلاة مع رسائل تشجيعية.
- **أناشيد مختارة:** قائمة من أرقى الأناشيد الإسلامية الهادفة والمؤثرة.
- **قصص الأنبياء والسيرة:** محتوى غني لتعلم سير الأنبياء والصالحين.
- **الخلوة والسكينة:** جلسات تأملية تساعد على طمأنينة القلب.
- **الاختبارات الإيمانية:** اختبر معلوماتك الدينية بأسلوب ممتع.

## التقنيات المستخدمة
- React + Vite
- Tailwind CSS (للواجهات الأنيقة)
- Firebase (لقاعدة البيانات والتوثيق)
- Framer Motion (للتحريكات الاحترافية)
